# 南陵祭2027 開発・運用ルール

## 1. コミットメッセージの厳格なフォーマット

- コミットを作成する際のコミットメッセージは、**必ず `CHANGELOG.md` で採番したバージョン番号のみ**（例: `0.1.1`）とすること。
- `feat:` や `fix:` などのプレフィックス、説明文、括弧（`[` や `]`）は一切含めず、純粋なバージョン文字列（例: `"0.1.1"`）にすること。
- Gitのコミットやプッシュは、ユーザーから明示的な指示（「コミットして」「プッシュして」等）があった場合のみ実行すること。

## 2. バージョニングと CHANGELOG.md の運用

- マイナーバージョン（`0.X.0`）やメジャーバージョン（`X.0.0`）の繰り上げは、ユーザーの明示的な承認・指示があった場合のみ行うこと。
- 日常的な変更・開発はすべてパッチバージョン（`0.0.Z`）をインクリメントすること。
- `CHANGELOG.md` を更新する際は、必ず事前に冒頭80行を読み、最新のパッチ番号と日付（JST）を確認し、一番上に追記すること。
- 知見や決定理由はすべて `CHANGELOG.md` を正として記録すること。
